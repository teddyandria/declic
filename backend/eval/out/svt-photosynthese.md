## Cartes

1. **[qcm]** Où se déroule la photosynthèse dans la plante ? _(8 mots)_
   - Choix : **Dans les feuilles** · Dans les racines · Dans les fruits · Dans les fleurs
   - Réponse : Dans les feuilles
   - Explication : La photosynthèse se fait dans les feuilles, pas dans les racines ou fleurs.
2. **[vrai_faux]** La chlorophylle est un pigment rouge dans les chloroplastes. _(9 mots)_
   - Réponse : Faux
   - Explication : La chlorophylle est un pigment vert, pas rouge.
3. **[trou]** La photosynthèse est le processus par lequel les plantes vertes fabriquent leur ___ organique. _(14 mots)_
   - Réponse : matière
   - Explication : Les plantes fabriquent leur matière organique grâce à la photosynthèse.
4. **[qcm]** Quel gaz entre dans la feuille par les stomates ? _(9 mots)_
   - Choix : Hydrogène · Azote · Oxygène · **Dioxyde de carbone**
   - Réponse : Dioxyde de carbone
   - Explication : Le dioxyde de carbone entre dans la feuille par les stomates.
5. **[vrai_faux]** La sève brute transporte l'eau dans la plante. _(8 mots)_
   - Réponse : Vrai
   - Explication : La sève brute fait circuler l'eau puisée par les racines.
6. **[trou]** La photosynthèse produit du glucose et rejette du ___ dans l'atmosphère. _(11 mots)_
   - Réponse : dioxygène
   - Explication : La photosynthèse rejette du dioxygène dans l'air.
7. **[vrai_faux]** La photosynthèse peut se faire sans lumière. _(7 mots)_
   - Réponse : Faux
   - Explication : Sans lumière, la photosynthèse s'arrête.
8. **[qcm]** Quel pigment vert contient les chloroplastes ? _(6 mots)_
   - Choix : **Chlorophylle** · Carotène · Anthocyane · Xanthophylle
   - Réponse : Chlorophylle
   - Explication : Les chloroplastes contiennent la chlorophylle, un pigment vert.
9. **[trou]** L'eau est puisée dans le sol par les ___. _(9 mots)_
   - Réponse : racines
   - Explication : Les racines puisent l'eau dans le sol.
10. **[vrai_faux]** Le glucose est transporté dans la plante par la sève élaborée. _(11 mots)_
   - Réponse : Vrai
   - Explication : La sève élaborée transporte le glucose dans la plante.
